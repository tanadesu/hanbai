# READ THE CROWD
会場の声を読んで、5分で売り切れ！

添付会場マップをそのまま使う、1人用のオフライン販売ゲームです。ビルド、外部API、ログイン、オンラインサーバーは不要です。

## 起動
`index.html` をブラウザで開くか、ローカルサーバーで起動します。

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

`http://127.0.0.1:4173` を開いてください。ランキングは同じブラウザ・URL内で localStorage に保存されます。

## 遊び方
「ゲーム開始」で5分の計測を開始。マップから売り場を選び「ここへ移動」、到着後に参加者コメントを読んで商品・数量・価格方針を選んで販売します。A室とB室の間は直通できず、ロビー経由で移動します。

毎回ランダムな販売目標が提示され、達成報酬が利益に加算されます。売上と報酬は画面で別々に確認できます。

## 調整
商品、売り場、コメント、需要、イベント、目標は `data.js` の `CONFIG` にまとめています。移動・販売・利益計算は `engine.js`、画面やランキングは `app.js`、来場者の動きは `crowd.js` です。マップ画像は `public/event-map-empty.png` と `public/event-map.png` にあります。

## 確認
```sh
node --test tests/engine.test.js
```
